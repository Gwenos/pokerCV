# Projet – Détection et identification de cartes au poker

## Description :
Ce projet introduit des notions de vision par ordinateur avec Python et OpenCV. 
L'obectif est de détecter et identifier les cartes qui compose une image et en déduire la main (au poker) du joueur.

## Limites et futur

A terme, ce projet pourrait :
- Prendre la superposition des cartes en considération
- Prendre plusieurs joueurs en considération
- Déterminer un gagnant parmis les joueurs
- Adapter le programme à un flux vidéo
